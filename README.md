# Zhanbo Li Academic Website

This site is built from the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

## Before publishing

Edit `_config.yml` and replace:

- `https://your-github-username.github.io`
- `your-github-username/your-github-username.github.io`

with your real GitHub Pages URL and repository path.

## Deploy

1. Create a repository named `your-github-username.github.io`.
2. Upload this folder's contents to the repository root.
3. In GitHub, open `Settings > Pages`.
4. Use the `main` branch and root folder.

GitHub Pages will build the Jekyll site automatically.
